# **洛谷P1196 [NOI2002] 银河英雄传说**   
## **1.审题**    
这道题涉及到队列之间的合并，自然的就会想到用并查集来实现  
但是同时他还要求我们输出计算两个战舰之间的距离，我们想到的是在并查集的基础上维护一个距离函数dis[x],让他等于x与fa[x]的距离  
为了实现这一点，我们要在fa[x]改变的时候改变dis[x]，具体为  
* 当我们调用find()的时候，我的做法是让find()不仅返回根节点，还返回其与根节点的距离。可以用make pair来实现这一点，但是我比较懒，就把dis*30001+根节点返回了，用的时候再拆
* 当我们合并两个舰队的时候，于是我们显然还需要一个数组siz[]来记录每一个舰队的大小，这样位于后面的舰队才能知道自己的具体位置。  
## **2.代码实现**
```cpp
#include<bits/stdc++.h>
using namespace std;
int fa[30010],dis[30010],siz[30010],q;
int find(int x)
{
    if(fa[x]==x)return x;
    int tmp=find(fa[x]);
    fa[x]=tmp%30001;
    dis[x]+=tmp/30001;
    return fa[x]+dis[x]*30001;
}
void ad(int x,int y)
{
    int fx=find(x)%30001,fy=find(y)%30001;
    fa[fx]=fy;
    dis[fx]=siz[fy];
    siz[fy]+=siz[fx];

}
int main()
{
    for(int i=1;i<=30000;i++)
    {
        fa[i]=i;
        dis[i]=0;
        siz[i]=1;
    }
    cin>>q;
    for(int i=1;i<=q;i++)
    {
        char tmpc;int tmpx,tmpy;
        cin>>tmpc>>tmpx>>tmpy;
        if(tmpc=='M')ad(tmpx,tmpy);
        else 
        {
            int fx=find(tmpx)%30001,fy=find(tmpy)%30001;
            if(fx!=fy)
            {
                cout<<-1<<endl;
                continue;
            }

            cout<<abs(dis[tmpx]-dis[tmpy])-1<<endl;
        }
    }
}
```
