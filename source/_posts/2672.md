# **洛谷P2672 [NOIP 2015 普及组] 推销员题解**
## **0.前言**
应该是独立做出的第一道蓝题，可能技术含量不是很高并且有简单很多的解法，但是还是挺有成就感的
可能比这道题更难的是找封面。
（哦对了封面是我的桌面壁纸
## **1.审题：贪心**  
我们不难发现如果每一步都按当下的最优解走，那整体上就是最优的。严谨的证明可以用冒泡排序的思想调整去每一住户的顺序，证明从略。
## **2.思路**
为了找到**当下的最优解**，我们需要将住户分为两类  
- 到入口的距离小于等于当前以走过的最大距离的住户；对这种住户，如果把他加进推销名单，疲劳值只会增加推销这户用的Ai  
- 到入口的距离大于当前以走过的最大距离的住户；对这种住户，如果把他加进推销名单，疲劳值除了增加推销用的Ai,还会计算多走的距离，即2*(Si-Smax)   

因为在我们一步一步贪心时，这两类住户的贡献的内部大小关系不会改变，我们自然的想到让两类先内部比较，然后再比较两类的最大值。  
- 对前一类住户，我们只关心其中的最大值，且将住户剔除出类时我们只会去除最大的，所以我们可以用priority_queue来做
- 对后一类，如果我们提前将住户按距离排序，那每次都只是在查询从一个住户到最远的住户的最大值，我们可以通过简单的从后往前的预处理实现。
## **3.代码实现**
```cpp
#include<bits/stdc++.h>
using namespace std;
int n,maxid[100010];
priority_queue<int>q;
struct node
{
    int s,a;
}p[100010];
bool cmp(node x,node y)
{
    return x.s<y.s;
}

int main()
{
    cin>>n;
    for(int i=1;i<=n;i++)cin>>p[i].s;
    for(int i=1;i<=n;i++)cin>>p[i].a;
    sort(p+1,p+n+1,cmp);
    int maxn=0,idx=0;
    for(int i=n;i>=1;i--)
    {
        if(p[i].s*2+p[i].a>maxn)
        {
            maxn=p[i].s*2+p[i].a;
            idx=i;
        }
        maxid[i]=idx;
    }
    int nb=0,ans=0,max1,max2;
    for(int i=1;i<=n;i++)
    {
        max1=0;max2=0;
        if(i==1)
        {
            nb=maxid[1];
            for(int i=1;i<=nb-1;i++)
            {
                q.push(p[i].a);
            }
            ans+=(p[nb].a+p[nb].s*2);
            cout<<ans<<endl;
            continue;
        }
        if(nb!=n)max1=p[maxid[nb+1]].a+2*p[maxid[nb+1]].s-2*p[nb].s;
        if(!q.empty())max2=q.top();
        if(max2>=max1)
        {
            ans+=max2;
            q.pop();
        }
        else 
        {
            for(int i=nb+1;i<=maxid[nb+1]-1;i++)q.push(p[i].a);
            ans+=max1;
            nb=maxid[nb+1];
        }
        cout<<ans<<endl;
    }
    
}
'''
